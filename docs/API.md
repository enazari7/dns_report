# HTTP API reference

Every route, what it returns, and which role it needs. Generated by hand from
`app.py` — if you add a route, add it here.

## Conventions

- All `/api/*` routes need a valid session cookie except where noted.
- **Role**: `session` = any logged-in user including the read-only viewer;
  `operator` = the write-capable account only. Enforced server-side.
- Every state-changing `POST` requires the header `X-CSRF-Token`, whose value
  is in `data-csrf` on the `<body>` of the dashboard page.
- A **bilingual message** is `{"en": "...", "fa": "..."}`. Anything the server
  generates for a human to read uses this shape so the browser can switch
  language without refetching.
- Paths are relative to `root_path` when that is configured.

### `GET /events` — session

Server-Sent Events. Event names: `hello`, `status`, `feed`, `unproxied`,
`events`, `error`. A `: ping` comment every 15s keeps the connection open.

**Behind a reverse proxy this needs `proxy_buffering off;`** or rows arrive in
clumps, minutes late.

### `GET /api/feed` — session

Query: `limit` (≤2000), `client_ip`, `sni`, `problems_only`, `since_seq`.
Returns `{rows, seq, total}`; each row is a parsed access-log record including
`from_origin` / `to_origin` and the `problem` flag.

### `GET /api/clients` — session

Distinct client addresses in the feed ring, most recent first, with connection
and problem counts.

### `GET`/`POST /api/watch` — session (POST needs CSRF)

Get or set the client whose dnsdist ring is being polled. `POST {"client_ip":
""}` stops watching. `grepq` runs **only** while a client is selected.

### `GET /api/client/{client_ip}` — session

The combined debugging view: `proxy_rows` (what sniproxy routed) plus `grepq`
(what went upstream), with `seen_in_proxy_log` cross-referenced per name, plus
the bilingual `permitted_hint`.

## The allow-list

### `GET /api/domains` — session

Entries with line numbers, groups and comments, plus `duplicates`, `invalid`
and `redundant`.

### `GET /api/groups` — session

```jsonc
{
  "groups": [ { "name": "codm", "state": "on|off|mixed",
                "active": ["..."], "disabled": ["..."],
                "active_count": 2, "disabled_count": 0 } ],
  "ungrouped": 4,
  "disabled": [ { "suffix": "...", "lineno": 12, "group": "codm" } ],
  "howto": { "en": "...", "fa": "..." }
}
```

### `POST /api/domains/preview` — operator, CSRF

Builds a plan. Nothing is written.

```jsonc
// request
{ "action": "add", "domain": "dl.newgame.net", "comment": "why", "group": "" }
```

`action` ∈ `add` | `disable` | `enable` | `tag` | `group-disable` |
`group-enable`. For the group actions, `domain` is the group name.

```jsonc
// response
{
  "token": "single-use, 5 minutes",
  "action": "add", "target": "dl.newgame.net", "ok": true,
  "blockers": [ {"en": "...", "fa": "..."} ],   // ok is false when non-empty
  "warnings": [ ... ], "notes": [ ... ],
  "diff": "--- a/...\n+++ b/...\n+dl.newgame.net  # ...",
  "observed_subdomains": ["..."], "covered_by": null, "would_capture": [],
  "restart_units": ["sniproxy", "dnsdist"],
  "update_script": "/usr/local/bin/update-smartdns.sh",
  "backup_dir": "/root/smartdns-backups",
  "peer_reminder": {"en": "...", "fa": "..."}
}
```

A refused preview is audited.

### `POST /api/domains/apply` — operator, CSRF

```jsonc
{ "token": "...", "confirm": "dl.newgame.net" }   // confirm must equal target
```

Backs up, writes, runs the update script, restarts the units — in that order,
as one unit. Returns `{ok, steps: [{name, ok, detail}], backup, error, plan}`.

- A wrong `confirm` returns 400 and **puts the plan back**, so a typo does not
  force a re-preview.
- A changed file since the preview is refused.
- A failed update script restores the backup automatically.
- `409` if another change is already running.

### `POST /api/domains/apply-both` — operator, CSRF

Same body. Applies to the peer **first**, then here. Requires a configured
peer. Refused if the two lists already differ. Returns
`{ok, peer: {...}, local: {...}, error}`.

### `GET /api/changes` — session

In-memory change log for this process. The durable one is `/api/audit`.

## Lookup and probe

### `GET /api/lookup?name=&resolver=` — session

Does the name match an active suffix, which one, and what does `dig` return now.
Returns `matched_suffix`, `is_proxied`, `is_bare_root`, `spoofed_now`,
`spoofed_to`, `spoof_ip`, per-type `dig` results, a bilingual `verdict`, and
bilingual `warnings` for the inconsistent cases (matched but not spoofed;
spoofed but unmatched; AAAA present for a proxied name).

### `POST /api/probe` — session, CSRF

```jsonc
{ "domain": "dl.newgame.net", "resolver": "1.1.1.1" }
```

Active test from the server. Read-only, so the viewer may run it. Returns
`resolve`, `tls`, `http`, `ports`, bilingual `verdict` / `recommendation` /
`reasons`, `proxyable` (`true` | `false` | `null`), `matched_suffix` and
`already_listed`. 403 unless `[probe] enabled`.

## Two-server diff

| Method | Path | Role | Notes |
|---|---|---|---|
| GET | `/api/peer/probe` | session | SSH reachability, plus the paste-mode hint |
| GET | `/api/peer/diff` | session | Fetches the peer's list over SSH and compares. 502 on SSH failure |
| POST | `/api/peer/paste` | session, CSRF | `{"text": "...", "peer_name": "..."}` — no SSH needed |

All three return `{only_mine, only_theirs, both, in_sync, my_count,
their_count, message}` with a bilingual `message`.

## History, charts, events, audit

### `GET /api/history` — session

`store.stats()`: row counts, file size, retention, and the disclaimer string.

### `GET /api/traffic?hours=&client_ip=` — session

```jsonc
{
  "hours": 6, "bucket_seconds": 300,
  "series": [ { "bucket": 1785785400, "conns": 4, "problems": 1,
                "from_origin": 5763, "to_origin": 2128 } ],
  "top_clients": [ ... ], "top_snis": [ ... ],
  "problem_rate": { "conns": 4, "problems": 1, "rate": 0.25 },
  "disclaimer": { "en": "...not an accounting source...", "fa": "..." }
}
```

### `GET /api/events?limit=&open_only=` — session

`{enabled, open, recent, summary, notifiers, min_severity}`. Each event has
`fingerprint`, `kind`, `severity`, `subject`, `detail_en`, `detail_fa`,
`started_at`, `last_seen`, `resolved_at`, `occurrences`, `acked_at`.

A condition that stays true is **one** event with a duration, not one row per
poll, and events close themselves when the condition clears.

### `POST /api/events/ack` — operator, CSRF

`{"id": 12}`. Marks an event seen; it stays open.

### `GET /api/audit?limit=&action=&who=` — session

Durable record of every attempted change, **including refusals**. Each entry:
`ts`, `actor`, `actor_ip`, `action`, `target`, `outcome`, `detail`, `diff`,
`backup`.

### `GET /api/registry?limit=&contains=&upstream_only=` — session

Every hostname ever observed, with a `first_seen` that survives restarts — the
dnsdist ring forgets, this does not. Each row carries `matched_suffix`.

## Status codes

| Code | Meaning here |
|---|---|
| 302 | Not authenticated (page routes) |
| 400 | Bad input: not a hostname, not an IP, unknown action, expired plan, wrong confirmation |
| 401 | No or invalid session (API routes) |
| 403 | CSRF missing/wrong; read-only account attempting a write; feature disabled in config; source address not in `allow_ips`; bad metrics token |
| 404 | Unknown log, missing backup, feature disabled (`/metrics`, `/triage`) |
| 409 | Another change is already running |
| 502 | SSH to the peer failed |
